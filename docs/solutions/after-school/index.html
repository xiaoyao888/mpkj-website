托管辅导系统

家长看得到孩子在机构的一天

托管辅导系统面向午托、晚托、课后托管和寒暑假托管机构，以微信小程序作为家长与教师的日常入口，配套 Web 管理后台，覆盖报名缴费、考勤签到、请假审批、接送核验、每日报告、作业与餐饮记录等日常业务。

系统为前后端分离架构，后台菜单与权限由数据库动态下发，机构可按校区、角色（管理员 / 教务 / 财务）分配可见功能，经营分析与对账报表支撑多校区运营。

联系我们 电话咨询：15101612203

适用场景

这几类业务可以直接套用，或按现有流程做小幅改造。

✓

午托 / 晚托机构

日常接送、就餐和休息环节需要留痕，家长希望看到孩子到机构和离开的记录。

✓

课后托管与作业辅导

报名缴费、请假审批、作业布置与批改反馈集中在同一系统，减少微信群里翻记录。

✓

寒暑假托管营

短期班期滚动开班，需要每日报告、餐食记录和家长端通知。

✓

多校区托管品牌

按校区和班级管理学生档案，缴费与对账出报表，教务、财务各看各的功能。

系统构成

01

家长端小程序

孩子档案、考勤记录、请假申请、接送人管理、套餐报名与支付、成长记录查看。

02

教师端小程序

签到签退、请假处理、每日报告与作业、餐食记录发布。

03

Web 管理后台

Vue 3 + Element Plus，班级、学生、报名、财务与系统配置集中管理。

04

后端服务

Spring Boot 多模块，分别提供小程序接口与管理后台接口。

功能模块

报名与缴费

套餐上架与价格有效期、在线报名、待支付订单、微信支付与回调校验、订单查询。

学生与班级

学生档案、家长关联、班级维护、状态与容量管理。

考勤与请假

签到签退记录与汇总、家长请假申请、机构审批与审批留痕。

接送安全

接送人授权、接送码生成与核验、接送记录，保障离园环节可追溯。

成长记录

每日报告（辅导内容与表现评价）、作业布置与批改、每日餐食与菜品图片。

经营与对账

ECharts 经营分析、订单与对账报表、缴费与退款记录。

通知与互动

公告通知、意见反馈、待办事项与消息触达。

系统与权限

菜单 / 角色 / 用户三级权限，字典、参数配置、操作日志与文件管理。

报名缴费流程

  1. 01 查看套餐列表
  2. 02 套餐详情
  3. 03 选择孩子与起止日期
  4. 04 提交报名生成待支付订单
  5. 05 微信支付
  6. 06 支付回调校验
  7. 07 报名与订单状态同步
  8. 08 订单与支付结果展示

日常托管流程

  1. 01 签到 / 签退
  2. 02 接送人核验（接送码）
  3. 03 请假申请与审批
  4. 04 每日报告 / 作业 / 餐食记录
  5. 05 家长小程序查看
